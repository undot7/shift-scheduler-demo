# shift-scheduler-demo

サロン・飲食店など**複数店舗を持つ事業者向けシフト管理アプリの営業デモ**です。
サーバー・DB・外部APIを一切使わない静的構成で、`index.html` をダブルクリックするだけで動きます。

> ⚠️ 本リポジトリは商談用のデモです。登場する事業者・店舗・人物はすべて架空です。
> シフトの自動生成は**商談演出用の簡易ロジック（貪欲法）**であり、実案件では本格的なアルゴリズムに置き換える前提です。

## できること

| 視点 | 機能 |
|---|---|
| スタッフ | 公開済みシフトの確認（月カレンダー・**公休/有給も表示**）、希望休・**有給申請**・希望時間・希望パターンの提出、アプリ内通知、**自分の月間シフトの印刷（A4縦1枚）** |
| 店長 | シフト表グリッド（スタッフ×日付・**割当のない日は「公休」／有給は「有給」**）、提出された希望の自動反映表示、セルタップで手動入力・編集・**有給登録**、**スタッフ名タップで個人設定**、シフト自動生成、下書き→公開（公開時に全員へ通知・公開後の変更は本人へ差分通知）、店舗条件の設定、**扶養超過見込みの警告**、**月間シフト表の印刷（A4横1枚）**、**CSVダウンロード** |
| オーナー | 3店舗の横断ダッシュボード（**店舗ごとの扶養超過見込み人数**）、各店舗のシフト表操作（店長と同等）、**共通設定（雇用形態ごとの既定実働時間・休憩の自動ルール・シフトパターン登録・店舗ごとの使用パターン・扶養の上限額）**、**個人設定（スタッフごとの時給・扶養区分など）** |

- 認証はありません。初期画面の**視点切替**でオーナー／店長／スタッフをワンタップで行き来できます
- データはブラウザのlocalStorageにのみ保存されます（サーバー送信なし）
- 店舗は「パターン制（早番/遅番など）」と「自由時間制（時刻指定）」の2方式に対応。**自由時間制の店舗でもパターンを使えます**

### 休憩の決まり方（2段階）

休憩は**2段階**だけで決まります。分かりやすさのため、これ以上は増やしていません。

1. **パターンに休憩が設定されていれば、それを使う**（パターン編集の「手動◯分」。0分も明示できます）
2. 設定が無ければ（「自動」）、**休憩の自動ルール（段階制）**で決まります

雇用形態（社員・パートなど）が持つのは**実働時間だけ**で、休憩は持ちません。

セル編集モーダルには「休憩 45分（休憩の自動ルール）・実働 8h」のように、**どちらが効いたか**が出ます。

### 共通設定（オーナー）

全店舗に効く設定です。オーナーのダッシュボード右上「⚙ 共通設定」から開きます。

- **雇用形態ごとの既定実働時間**: 実働時間を雇用形態（店長・社員・パート・学生）ごとに設定します（休憩は持ちません）
  - 初期値は 店長/社員＝**実働8時間**（＋自動ルールの休憩45分＝**拘束8時間45分**）、パート＝実働5時間、学生＝実働4時間
  - **自由時間制の店舗の自動生成**で「1コマの長さ」に使います。**パターン制の店舗はパターンの時刻が優先される**ため、この設定は使われません
  - **店長は各セルを開いて任意の時刻に変更できます**（既定はあくまで初期値）
  - 実働時間は**16時間まで**です（それを超える値は保存時に止まります）
- **休憩の自動ルール（段階制）**: 拘束時間から休憩を決めるルールです
  - 初期値は `拘束6時間以下→0分` / `拘束8時間45分以下→45分` / `それ超→60分`
  - 労働基準法34条（実働6時間超で45分・8時間超で60分）を拘束時間に置き換えたものです。実働8時間＋休憩45分＝拘束8時間45分が境目になるため、拘束時間だけで同じ判定ができます
  - **閾値と分数はすべてこの画面で変更できます**（法令の数字をアプリに焼き込んでいません）
- **シフトパターン（全店共通）**: 名前・開始・終了・**休憩（自動／手動◯分）**・色を登録します。名前は自由入力で `A` `B` `C` でも `早番` `遅番` でも構いません
  - 例: `A 10:00〜19:00（休憩60分＝実働8時間）`
  - 削除しても既存シフトの時刻は消えません（パターン名が外れるだけ／提出済みの希望は時間指定に変わります）。**公開済みのシフトも対象**で、スタッフのカレンダーの表示が「中番」から「10:00-18:00」に変わります。削除は元に戻せないため、確認画面に対象件数（うち公開済み件数）を出しています
  - ⚠️ **パターンの時刻を編集しても、すでに作成済みのシフトの時刻は変わりません**（過去に組んだシフトを勝手に書き換えないための仕様です）。そのため、時刻を変えたパターンでは「シフト表のパターン名」と「実際の時刻」が食い違うことがあります（CSVでも同様）。作り直したい月は**自動生成をやり直してください**
- **店舗ごとの使用パターン**: 共通設定で1セット登録し、店舗ごとに使うものをチェックで選びます
  - **自由時間制の店舗では手動あてはめ用**です（自動生成には使われません。店長がセルにあてはめて微調整するときと、スタッフのパターン希望で使えます）
- **扶養の上限額（年間）**: 扶養計算の基準額です。初期値は123万円
  - 基準額は改正が続いているため、**固定値ではなく設定値**にしています

### 個人設定（スタッフごと）

**店長のシフト表でスタッフ名をタップ**、または**オーナーのダッシュボード「👤 個人設定」**から開きます。

| 項目 | 内容 |
|---|---|
| 雇用形態 | 共通設定で定義した雇用形態から選択（既定の実働時間が変わります） |
| 週の最大勤務日数 | 空欄＝制限なし。自動生成が守ります |
| 出勤可能曜日 | 全曜日チェック＝制限なし。自動生成が守ります |
| 時給 | 扶養計算に使います（未設定なら計算対象外） |
| 年初〜先月の累計額 | 扶養計算の起点。すでに支払われた額です |
| 扶養の区分 | **扶養内**（計算・警告の対象）／**扶養外**（対象外）。既定は 社員・店長＝扶養外、パート・学生＝扶養内 |

- **休憩は個人ごとには設定しません**（上の「休憩の決まり方」の2段階を保つためです）

### 扶養範囲内の計算

- **見込み額 = その月のシフトの「実働時間 × 時給」**。休憩を引いた実働で計算するので、休憩ルールがそのまま効きます
- **累計（年初〜前月）＋ 見込み** が上限額を超えると、超過見込みとして表示します
  - 店長のシフト表: スタッフ名の下に **⚠扶養超過見込み**、ツールバーに **⚠ 扶養超過見込み ◯名**
  - オーナーのダッシュボード: 店舗ごとに **⚠ 扶養超過見込み ◯名** と対象者名
  - セル編集・個人設定: 「累計 ＋ 当月見込み ＝ 合計 ／ 上限」と**残額（または超過額）**
- **扶養外のスタッフは計算・警告の対象外**です。個人設定で扶養外に切り替えると、その場で警告が消えます
- 給与情報のため、**扶養の警告は印刷では出しません**（画面のみ）
- ⚠️ **自動生成の制約には入れていません**（表示・警告のみ）。「超えそうな人が赤く出る → 店長が手で直す」までがデモ版の範囲です
- デモの時給・累計額は架空の値です。**累計額は開いた月に合わせて生成**されます（年初〜先月の月数×月平均額）。そのため年の前半に開くと累計が小さく、超過見込みが出ないことがあります（個人設定で累計額を変えればその場で再現できます）

### 休み・有給の扱い

- 割当のない日は**空欄にせず「公休」**と表示します（画面・印刷とも）。**希望休が通った日も「公休」**に統一し、紙面で「希望休」と二重に出ないようにしています（画面では小さく「希望」と併記され、店長は由来を追えます）
- 「公休」と表示するのは**シフト表を作成した月（自動生成または公開を行った月）だけ**です。未作成の月は、提出された希望だけが表示されます（手動で1セル入れただけの月が完成シフト表に見えないようにするため）
- **有給**は公休とは別枠です
  - 入力経路は2つ: スタッフの「🏖 有給申請」／店長のセル編集「🏖 有給にする」。どちらも同じデータとして扱われます
  - **自動生成は有給を新たに割り当てず、既にある有給を消しません**（希望休と同じ絶対条件）
  - **有給の日は月の公休日数にカウントしません**（有給を取るほど公休が減る形にはなりません）
  - 有給で人が減った日は**「⚠️不足」バッジに反映**されます
- **希望休は月3日まで**。4日目を出そうとすると理由を出して止まります。**有給はこの3日に含みません**
- 白黒印刷でも判別できるよう、公休＝点線枠・有給＝実線枠で、いずれも文字（公休／有給）を必ず出します

### 印刷について

- 月間シフト表は**A4横1枚**、スタッフ個人分は**A4縦1枚**に収まります（用紙向きは印刷対象に合わせて自動で切り替わります）
- 画面のボタン類・タブ・ヘッダーは紙に出ません。代わりに**店舗名／対象月／出力日時／状態**の見出しが入ります
- **未公開のまま印刷すると紙面に「下書き（未公開）」と明示されます**（確定版との取り違え防止）
- **白黒コピーでも読めます**。地色は白・文字は黒にし、店舗色/パターン色は左端の色帯で残したうえで、パターン名と開始/終了時刻を必ず併記しています
- スタッフ数が1枚に収まらない場合はスタッフ単位で改ページし、日付ヘッダー行を各ページで繰り返します

### CSVダウンロードについて

- 1行=1シフト。列は `店舗名, 日付, スタッフ名, 開始時刻, 終了時刻, パターン名, 休憩(分), 実働時間(h)`
  - **パターン名**はパターンをあてはめていないシフトで空欄になります（自由時間制の店舗でもパターンをあてはめれば名前が入り、パターン制の店舗でも時刻を手入力したシフトは空欄になります）
  - **休憩・実働時間**は v1.4 で追加した列です（既存の列順は変えていません）。実働時間は `終了 − 開始 − 休憩` を時間の小数（例 `7.25`）で出すので、**Excel側でも時給を掛けるだけで同じ扶養計算ができます**
- ファイル名は `シフト_{店舗名}_{YYYY-MM}.csv`。**下書き（未公開）を含む状態では `シフト_{店舗名}_{YYYY-MM}_下書き.csv`** になり、確定版と取り違えません
- 公休・有給の日は行を作りません（1行=1シフトのため）
- **UTF-8 BOM付き**なのでExcelでそのまま開いても文字化けしません
- ブラウザ内で生成して保存するだけで、サーバーには一切送信しません（`file://` で開いた状態でも動作します）

## 商談での見せ方（デモシナリオ）

1. **スタッフ視点**（例: 田中 優奈）→「希望提出」タブ → 来月の日付をタップ → **希望休を提出**。同じモーダルから**「🏖 有給申請」**も出せる（残数「希望休 N / 3日」が出る）
   - 続けて**鈴木 恵子**の視点に切り替えると希望休が既に**上限の3日**。4日目を出そうとすると「希望休は月3日までです」と止まる → **ルール違反を提出前に防げる**ことが見せられる
2. **視点切替 → 店長（本店）**: シフト表グリッドに今の希望休・有給が**即座に反映されている**ことを見せる。セルをタップすれば店長側からも**「有給にする」**が選べる
3. **条件設定**を開き、公休日数・最大連勤・必要人数が設定できることを見せる
   - あわせて**オーナー視点の「⚙ 共通設定」**を見せる:
     - **雇用形態ごとの既定実働時間**（社員＝実働8時間 → 自動で休憩45分 → 拘束8時間45分）。**この設定が効くのは自由時間制の本店**なので、必ず本店の画面と並べて見せる
     - **休憩の自動ルール（段階制）**。「法律の数字を焼き込まず、設定で変えられます」が刺さるポイント
     - **シフトパターンをその場で追加できる**こと（`A 10:00〜19:00`／休憩は「自動」か「手動◯分」）。登録したパターンは店舗ごとにチェックで割り当てられ、**自由時間制の本店でもセルにあてはめて微調整できる**
4. **「自動生成」ボタン** → 数秒で来月のシフト表が埋まる（希望休・**有給**・週上限・連勤上限は守られる）。**空欄は残らず「公休」**が入り、有給の日は「有給」のまま触られない
5. **扶養の警告**（v1.4の見せ場）: 生成した瞬間、本店の**山本 典子**に「⚠扶養超過見込み」が出る
   - ツールバーにも「⚠ 扶養超過見込み 1名」。**今月/来月を切り替える**と、今月はまだ収まっていて**来月のシフトを組んだ時点で超える**ことが分かる
   - スタッフ名をタップ →**個人設定**で「累計 ＋ 当月見込み ＝ 合計 ／ 上限」と超過額を見せる
   - その場で**扶養区分を「扶養外」に切り替えると警告が消える**（戻せば復活）。「扶養内の人だけを見張ります」と説明できる
   - オーナーのダッシュボードにも店舗ごとの超過見込み人数が出る
6. **「印刷」**（公開前に押すと紙面に「下書き（未公開）」と出る）→ プレビューで**A4横1枚に収まったシフト表**を見せる。**扶養の警告は紙には出ない**（給与情報のため）。**「CSVダウンロード」**でExcelに渡せることも見せる（**休憩・実働時間の列があるので、Excel側でも同じ扶養計算ができる**）
7. **「シフトを公開」** → スタッフ視点に切り替え → **通知**が届き、カレンダーにシフトが表示されている
8. スタッフ画面の「**このシフトを印刷**」→ 個人分がA4縦1枚で出る（休憩室に貼る／本人に渡す用途）
9. **視点切替 → オーナー**: 3店舗の横断ダッシュボードを見せる
10. 右上の⚙ →「**デモデータにリセット**」で初期状態に戻す（何度でも繰り返せます）

> 💡 デモデータの日付は「開いた日」を基準に生成されます。前回開いた日から日付が変わっている場合は、**最初に「デモデータにリセット」してから**始めてください。

補足の小ネタ:
- 条件設定で必要人数を増やして再生成すると、埋められない日に「⚠️不足」バッジが出ます（"無理な日はちゃんと教えてくれます"）
- 共通設定で**パターンを1つ追加**して、パターン制の店舗（駅前店）に割り当ててから条件設定を開くと、**「実効◯%」**が表示されます。入力した割合の合計が100%でなくても比率として正規化されるので、"パターンを増やしても割合の設定をやり直さなくていい"と言えます
- 有給を入れた日は人手が減るので、そのまま**「⚠️不足」に反映**されます（"有給を入れたら足りない日が見える"）
- 公開済みの月のセルを変更すると、該当スタッフだけに差分通知が届きます
- 印刷プレビューは**公開前と公開後で紙面の表記が変わります**（下書きは「下書き（未公開）」の枠が付く）。並べて見せると刺さります

## 技術構成

- `index.html`（HTML/CSS/JS同梱・フレームワークなし・CDNなし）+ `demo-data.js`（デモデータ）の2ファイル構成
- オフラインで完全動作（`file://` で直接開いてOK）。データ読み込みにfetchは使っていません
- 印刷は `@media print` と `@page` のみ、CSV書き出しは `Blob` + `URL.createObjectURL()` のみで実装（PDF/Excel系の外部ライブラリは不使用）
- デモデータの日付は「今日」を基準に動的生成されるため、いつ開いても今月・来月のデモができます

### 自動生成ロジックについて（簡易版）

`index.html` 内 `generateForMonth()`。乱数を使わない決定的な貪欲法です（リハーサルと本番で同じ結果になります）。

1. 希望休**と有給**の日は割り当てない（有給は消さない・上書きしない）／希望時間・希望パターンは月全体で最優先割り当て（本人の明示希望は曜日制限・上限チェックより優先）
2. それ以外の割り当てでは週最大勤務日数・最大連勤・月の公休日数・出勤可能曜日を守る（**有給日数のぶん勤務可能日数を減らし、公休は設定どおり確保する**）
3. 日付順に、必要人数に達するまで「その月の勤務日数が少ない人」から割り当て（公休の均等化）
4. パターン制: パターンの割合が設定値（条件設定の「パターン割合（%）」）に近づくように選択。**割合は合計100%に正規化してから使う**（合計が100でなくても、パターンを追加・削除しても崩れない）
5. 自由時間制: 時間帯別必要人数を30分刻みで概ね満たすように開始/終了を割り当て。**1コマの長さは割り当てる人の雇用形態の既定実働＋自動ルールの休憩**を使う（**実働が4時間を下回らない**ように前後へ伸ばす）
6. 必要人数に達しない日は「⚠️不足」バッジを表示
7. **扶養は制約に入れていません**（表示・警告のみ）

**実案件ではこのロジックを本格的なアルゴリズム（別指示書）に置き換えます。**
